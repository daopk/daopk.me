# Repository Guidelines

## Git

- Use Conventional Commits for all commit messages.
- For app-specific changes, use the app id as the Conventional Commit scope, e.g. `feat(youtube-player): ...`.

## Local Testing

- Always use `http://127.0.0.1:5173/` for local browser testing. If that port already has a server running, use it directly instead of starting another dev server.
